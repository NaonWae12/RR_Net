# 🛡️ High-Performance VPN Gateway (accel-ppp) Guide
## 🌍 Environment: Ubuntu 24.04 LTS (Noble) | Kernel 6.8.0

Dokumentasi ini berisi langkah-langkah presisi untuk membangun infrastruktur VPN MikroTik (SSTP & L2TP) menggunakan `accel-ppp` v1.14.0 di Ubuntu Noble.

---

### 📦 1. Persiapan Dependency
Wajib diinstall sebelum mulai masak (compile):

```bash
sudo apt update
sudo apt install -y build-essential cmake gcc git libpcre2-dev libssl-dev \
    libnl-3-dev libnl-genl-3-dev zlib1g-dev pkg-config

# Wajib untuk L2TP Native Kernel Support
sudo apt install -y linux-modules-extra-$(uname -r)
sudo modprobe l2tp_ppp
```

---

### 🏗️ 2. Build dari Source & "Jiret" OpenSSL 3
Masalah utama di Ubuntu 24.04 adalah modul SSTP gagal nge-link ke OpenSSL 3 secara otomatis. Kita harus "Jiret" (patch) manual ke CMake-nya.

```bash
cd /tmp
git clone https://github.com/accel-ppp/accel-ppp.git
cd accel-ppp

# 🔥 TRIK RAHASIA: Patch Manual Linking SSL ke SSTP
echo "target_link_libraries(sstp ssl crypto)" >> accel-pppd/ctrl/sstp/CMakeLists.txt

# Bangun Dapur Bersih
rm -rf build && mkdir build && cd build

# Masak dengan "Bumbu Paksa" (Force Link OpenSSL 3 Multi-arch)
cmake .. \
 -DBUILD_PPTP_DRIVER=FALSE \
 -DBUILD_IPOE_DRIVER=FALSE \
 -DBUILD_L2TP_DRIVER=TRUE \
 -DKDIR=/lib/modules/$(uname -r)/build \
 -DOPENSSL_ROOT_DIR=/usr \
 -DOPENSSL_INCLUDE_DIR=/usr/include \
 -DOPENSSL_LIBRARIES="/usr/lib/x86_64-linux-gnu/libssl.so;/usr/lib/x86_64-linux-gnu/libcrypto.so"

make -j$(nproc)
sudo make install
```

### 🕵️‍♂️ 3. Validasi Binary (Wajib!)
Pastikan modul SSTP sudah punya "Otak" SSL, lewat perintah `ldd` dan `nm`:

```bash
# Harus muncul libssl.so.3
ldd /usr/local/lib64/accel-ppp/libsstp.so

# Harus muncul list symbol SSL (SSL_CTX_new, dll)
nm -D /usr/local/lib64/accel-ppp/libsstp.so | grep SSL
```

### ⚙️ 4. Konfigurasi "Anti-Keselek" (`accel-ppp.conf`)
Jangan menggunakan `tee` untuk teks panjang sekaligus karena shell bisa memotong baris secara diam-diam. Gunakan metode cicilan (`tee -a`).

#### A. Struktur Wajib `/etc/accel-ppp/accel-ppp.conf`
```ini
[modules]
log_syslog
cli
ppp
auth_mschap_v2
auth_chap_md5
auth_pap
ippool
chap-secrets
sigchld
sstp
l2tp

[core]
log-error=/var/log/accel-ppp/error.log
thread-count=4
# Wajib diarahkan ke folder hasil build kita
plugin-dir=/usr/local/lib64/accel-ppp

[cli]
tcp=127.0.0.1:2001

[sstp]
# Format Host & Port (Bukan bind=IP:PORT di versi 1.14)
host=0.0.0.0
port=4443
ssl=1
cert=/etc/accel-ppp/ssl/vpn.crt
key=/etc/accel-ppp/ssl/vpn.key

[l2tp]
bind=0.0.0.0
port=1701

[log]
log-syslog=accel-pppd
log-level=5
```

### 🚀 5. Runtime & Eksekusi
Agar modul berhasil di-load di sistem 64-bit, wajib mendaftarkan path library-nya.

```bash
# Sinkronkan folder lib64 ke lib (Bypass quirk loader Ubuntu)
sudo mkdir -p /usr/local/lib/accel-ppp
sudo ln -sf /usr/local/lib64/accel-ppp/* /usr/local/lib/accel-ppp/

# Jalankan secara permanen (Pastikan systemd service bawaan di-disable jika konflik)
export LD_LIBRARY_PATH=/usr/local/lib64/accel-ppp
sudo -E /usr/local/sbin/accel-pppd -d -c /etc/accel-ppp/accel-ppp.conf
```

---

### 🚨 6. Troubleshooting Playbook
- **Log Kosong**: Modul logging gagal load. Pastikan `LD_LIBRARY_PATH` ter-set lewat `sudo -E`.
- **4443 Gak Nongol**: Syntax `bind` salah. Gunakan `host=0.0.0.0` dan `port=4443`.
- **Conflict Process**: Jika port 4443/1701 hilang, cek `journalctl -u accel-ppp`. Biasanya ada perang antara *Systemd Service* vs *Manual Process*.
