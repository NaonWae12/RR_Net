📜 PENJELASAN ATURAN PROGRAM AFFILIATE
🎯 Gambaran Umum

Program affiliate ini memungkinkan siapa saja untuk mendapatkan komisi dengan mengajak orang lain berlangganan layanan ERP.

Program ini terbuka untuk:

Tenant (client utama)

Client dari tenant

Umum (non-client)

💰 Cara Kerja Komisi

Affiliator membagikan kode referral.

Client mendaftar dan menggunakan kode tersebut.

Setiap kali client melakukan pembayaran langganan:

Affiliator akan mendapatkan komisi sesuai persentase.

👉 Komisi akan terus didapatkan selama client masih aktif berlangganan.

👉 Jika client berhenti berlangganan:

Komisi otomatis berhenti.

📊 Besaran Komisi

Komisi dimulai dari 15% hingga 35%

Persentase bisa meningkat berdasarkan performa (jumlah referral / tenant yang diajak)

Contoh:

Mengajak 2 tenant → naik +5%

Mengajak 4 tenant → naik lagi +5%

⏳ Pencairan Komisi

Komisi akan masuk ke Wallet Balance

Komisi dapat dicairkan setelah 28 hari sejak pembayaran berhasil

👉 Tujuan:

memastikan transaksi valid

menghindari penyalahgunaan/refund

👛 Wallet Balance

Saldo komisi yang didapat akan masuk ke wallet dan bisa digunakan untuk:

Withdraw (ditarik sebagai uang)

Membayar layanan (khusus tenant)

🔁 Sistem Subscription (Kunci Utama)

Komisi diberikan setiap kali client melakukan pembayaran (bulanan/tahunan)

Jika client terus berlangganan → komisi terus berjalan

Jika client berhenti → komisi ikut berhenti

👉 Affiliator dianjurkan menjaga hubungan dengan client agar tetap aktif

🎁 Keuntungan untuk Client (yang pakai referral)

Client yang menggunakan kode referral akan mendapatkan:

Diskon 10%

Berlaku untuk 2 kali pembayaran

Bisa digunakan kapan saja (tidak harus langsung)

🔒 Sistem Penguncian Referral

Client hanya bisa menggunakan 1 kode referral

Setelah digunakan:

Tidak bisa diganti

Tidak bisa menggunakan kode lain

👉 Ini untuk menjaga keadilan antar affiliator

🚫 Pencegahan Penyalahgunaan

Untuk menjaga sistem tetap adil:

Komisi hanya dihitung dari pembayaran valid

Sistem memiliki monitoring transaksi

Akun dengan indikasi penyalahgunaan dapat ditinjau atau dibatasi

🧠 Catatan Penting

Komisi berbasis performa (bukan gaji tetap)

Semakin banyak dan aktif client → semakin besar penghasilan

Sistem ini dirancang untuk jangka panjang (bukan sekali jual)
